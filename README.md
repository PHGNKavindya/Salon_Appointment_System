# 💇 Salon Appointment System

A simple **Python mini project** for managing salon appointments through a command-line interface.

## 📌 Overview

The Salon Appointment System allows users to view available salon services and prices, book appointments, view existing appointments, and cancel appointments.

Appointment information is stored in a **CSV file**, allowing previously saved appointments to be loaded when the application is started again.

## ✨ Features

* View available salon services and prices
* Book a new appointment
* View all appointments
* Cancel an appointment using the contact number
* Save appointment data to a CSV file
* Load previously saved appointments
* Basic service validation

## 🛠️ Technologies & Concepts

* **Python 3**
* CSV File Handling
* Lists
* Dictionaries
* Functions
* Basic Input Validation
* Command-Line Interface (CLI)

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/salon-appointment-system.git
```

### 2. Navigate to the project folder

```bash
cd salon-appointment-system
```

### 3. Run the Python program

```bash
python salon_appointment_system.py
```

## 📋 Main Menu

The application provides the following options:

1. Available Services and Prices
2. Book an Appointment
3. View All Appointments
4. Cancel an Appointment
5. Exit

## 💾 Data Storage

The application uses an `appointments.csv` file to store appointment information.

The CSV file contains:

* Appointment ID
* Customer Name
* Contact Number
* Appointment Date
* Service

The file is created automatically when appointments are saved.
